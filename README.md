# Monitoring Infrastructure

## Description

This project demonstrates a monitoring infrastructure using Docker, Prometheus and Grafana.

## Technologies

- Docker
- Docker Compose
- Prometheus
- Grafana
- Linux

## Features

- CPU Monitoring
- Memory Monitoring
- Disk Monitoring
- Dashboard Visualization

## Architecture

Prometheus collects metrics from monitored systems and Grafana provides dashboards for visualization.
